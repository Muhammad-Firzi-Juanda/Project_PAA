📋 Cara Penggunaan:

1. Klik "🖼️ Pilih Gambar Peta" untuk upload

2. Jalan akan terdeteksi otomatis

3. Klik pada canvas untuk set posisi player

4. Ctrl+Klik untuk set tujuan

5. Klik "Start" untuk mulai navigasi

6. Sesuaikan threshold jika deteksi kurang akurat

🎮 Kontrol:

Klik: Set posisi player

Ctrl+Klik: Set tujuan

Start: Mulai navigasi

Stop: Hentikan navigasi

Acak: Posisi acak

⚙️ Tips:

• Gambar dengan kontras tinggi lebih mudah dideteksi

• Threshold rendah = deteksi area gelap

• Threshold tinggi = deteksi area terang
